# PBH_CosmicArchitects
PBH Analysis Code for "Primordial Black Holes as Cosmic Architects: Imprints of an extended mass function".
If you use this code, please cite the associated paper.

The main script used to produce the results presented in the paper is "PBH_CosmicArchitects.ipynb".

All other files in this repository (data files, input tables, and mass functions) are required for the notebook to run correctly. They provide the necessary inputs for the PBH mass function, detector sensitivity curves, observational datasets, and gravitational-wave event catalogs.

Please ensure that all files are kept in the same directory structure when running the notebook, as the code expects these inputs to be locally available.
